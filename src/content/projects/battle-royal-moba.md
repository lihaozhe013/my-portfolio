## Overview

Battle Royal Moba is a game development project built with Godot. The project
explores how multiplayer arena mechanics, real-time combat, and a readable game
space can work together in a compact game loop.

## Technology

- Godot for the game engine and scene workflow
- GDScript for gameplay logic and iteration
- C++ for lower-level and performance-sensitive work

The project is still evolving, so this page will grow with new gameplay systems,
playable builds, and technical notes.
