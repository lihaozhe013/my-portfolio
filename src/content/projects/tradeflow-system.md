## Overview

TradeFlow is a lightweight trade management system designed for small
businesses. It was developed from interface design through deployment, with a
React frontend and a Node.js and PostgreSQL backend.

## Key capabilities

- Inventory, product, and pricing management
- Accounts payable and accounts receivable tracking
- Sales analysis and Excel data export
- Stateless JWT authentication
- Editor and Viewer role-based access control
- Multi-language support for English, Korean, and Chinese

## Architecture

The frontend is built with React 19, Vite, TypeScript, Ant Design, and Tailwind
CSS. The backend uses Node.js, Express, PostgreSQL, and TypeScript. Decimal.js
is used for precise financial calculations, while GitHub Actions and Argo CD
support the deployment workflow.

## What I focused on

The project connects day-to-day business workflows with a clear interface:
inventory changes, financial records, permissions, and reports are represented
as one consistent system instead of isolated tools.
